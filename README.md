# EduSpark — Responsive Product Landing Page

## 1. Project Overview

EduSpark is a fictional online learning platform designed to help students discover courses, develop new skills, and track their learning progress.

This project was created as an individual UI/UX design assignment using Figma.

## 2. Target Audience

- College students
- Beginners learning new skills
- Students interested in technology and professional development

## 3. Project Objectives

- Design a visually appealing product landing page.
- Present the platform's features clearly.
- Encourage users to explore courses.
- Create a layout for desktop and mobile screens.

## 4. Tools Used

- Figma
- Auto Layout
- Reusable Components
- Typography and Color Styles

## 5. Main Sections

1. Header and Navigation
2. Hero Section
3. Features Section
4. Popular Courses
5. Student Testimonials
6. Call-to-Action Banner
7. Footer

## 6. Reusable Components

- Primary Button
- Feature Card
- Course Card
- Testimonial Card

## 7. Design Choices

- **Primary color:** Purple (#6D28D9)
- **Background:** Light lavender (#F8F7FF)
- **Typography:** Inter
- **Layout:** Auto Layout for spacing and alignment
- **Responsive design:** Separate desktop and mobile layouts
